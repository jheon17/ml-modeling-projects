# ML Modeling Projects

회귀, 분류, 시계열 등 다양한 머신러닝 문제를 직접 모델링하며 전체 분석 과정을 학습하고 기록하는 프로젝트 모음입니다.

단순히 모델을 실행하는 것보다 문제 정의부터 데이터 확인, 전처리, 기준 모델 설정, 모델 평가, 오류 분석까지의 과정을 이해하고 재현하는 것을 목표로 합니다.

## 진행 원칙

- 실제로 실행하고 확인한 결과만 기록합니다.
- 모델 성능은 기준 모델과 비교하여 평가합니다.
- 전처리와 모델 선택의 이유를 기록합니다.
- 실패하거나 기대와 달랐던 결과도 문제 해결 과정으로 남깁니다.
- 원본 데이터는 저장소에 포함하지 않고 출처를 명시합니다.

## 개발 환경

프로젝트 공통 Python 환경과 dependency는 `uv`로 관리합니다.

현재 확인된 환경:

- Python 3.13.15
- uv 0.12.9

세부 dependency는 `pyproject.toml`과 `uv.lock`에서 관리합니다.
